# Часто задаваемые вопросы

## Что такое Ethereal?

Ethereal — это root-решение на основе модуля ядра для ARM64 GKI 1.0 и GKI 2.0. Оно загружает `ethereal.ko` из загрузочного ramdisk, не перезаписывая kernel Image.

## Что изменяет патч загрузочного образа?

- GKI 1.0: `ethereal-init`, KO и остальные загрузочные файлы добавляются в ramdisk образа `boot.img`; `rdinit=/ethereal-init` добавляется в cmdline того же `boot.img`.
- GKI 2.0: файлы добавляются в ramdisk образа `init_boot.img`, а `rdinit=/ethereal-init` — в cmdline соответствующего `boot.img`. Поэтому оба образа нужно патчить вместе.

Ядро сначала запускает `/ethereal-init`. Он выбирает KMI-модуль, точно соответствующий release работающего ядра, загружает его через `finit_module()`, а затем запускает штатный `/init`. Ethereal не заменяет `/init` и не изменяет его точку входа ELF.

## Почему нет одного универсального KO?

Ядра с одинаковой основной версией могут использовать разные Android KMI, версии символов и CRC. Ethereal собирает отдельный KO для каждого поддерживаемого KMI и загружает только однозначное совпадение. Если точного совпадения нет, загрузка системы продолжается без Ethereal.
