# Часто задаваемые вопросы

## Что такое Ethereal?

Ethereal — это root-решение на основе модуля ядра для ARM64 GKI 1.0 и GKI 2.0. Оно загружает `ethereal.ko` из загрузочного ramdisk, не перезаписывая kernel Image.

## Что изменяет патч загрузочного образа?

- GKI 1.0: `ethereal-init`, KO и остальные загрузочные файлы добавляются в ramdisk образа `boot.img`; `rdinit=/ethereal-init` добавляется в cmdline того же `boot.img`.
- Офлайн-патч GKI 2.0: выбирается только один `init_boot.img`. Файлы добавляются в него, штатный `/init` сохраняется как `init.ethereal.bak`, а дополнительный `PT_LOAD` перенаправляет точку входа ELF через загрузчик Ethereal. Соответствующий `boot.img` и его cmdline не меняются. GKI 2.0 `boot.img`, содержащий только ядро, отклоняется как отдельная цель. Direct Install по-прежнему патчит `init_boot` и `boot` вместе в одной транзакции.

GKI 1.0 и Direct Install запускают `/ethereal-init` через `rdinit`. Офлайн-путь GKI 2.0 входит в загрузчик, внедрённый в штатный `/init`, загружает точный KMI-модуль через `finit_module()`, а затем переходит к исходной точке входа ELF. Штатный файл не заменяется; снятие патча восстанавливает его из `init.ethereal.bak`.

## Почему нет одного универсального KO?

Ядра с одинаковой основной версией могут использовать разные Android KMI, версии символов и CRC. Ethereal собирает отдельный KO для каждого поддерживаемого KMI и загружает только однозначное совпадение. Если точного совпадения нет, загрузка системы продолжается без Ethereal.
